Help and support

Free and Pro

Recording, import, playback, export and existing text access/editing/copying/read aloud are free. Pro is a one-time purchase (US $2.99; localized Apple price), unlocking new offline transcription with speaker labels, proofreading, summaries and personal terminology. Restore Purchases and Redeem Code use Apple. Optional cloud API fees are separate.

Transcribe and review

Save or import audio, open Transcript and Summary, select Mandarin, English or Japanese, then Transcribe. No API key is needed for local recognition. Check estimated speaker labels and uncertain speech. Edit as New Version preserves the original. History groups related versions; expand All Versions. Before summarizing, choose the exact text source. Partial text is usable with an incompleteness warning.

Listen to text

Open the full transcript, corrected text or summary, then tap Read Aloud to read its text. In the detail screen, filtering a speaker offers Read This Speaker. Use pause, continue and stop in the app or system playback controls. Available iOS voices are used; missing voices require system setup, never cloud fallback. Locking or switching apps can continue real playback. Calls or removed headsets pause; resume manually. Starting recording stops read aloud. Local transcription is exclusive; cloud text tasks can run with recording or read aloud.

AI configuration

Use your own valid text-service key and supported model. Test Interface sends only fixed test text after confirmation and may cost money; it does not test audio transcription. Review the destination before sending private text. File/JSON/QR configuration sharing includes readable keys; send only to trusted recipients. Revoke a shared key through its provider if needed.

Long recordings and interruptions

Start recording in the foreground. Available inputs can recover automatically; phone/Siri interruptions resume only if the system permits and you have not cancelled. Gaps are possible. Saved recordings retain short segments; closed segments compress when possible. Stop does not merge the full recording. Export creates one M4A and needs extra storage. Checkpoints are local recovery, not an external backup. Phone/WeChat call audio capture and live translation are not supported.

Power, background and recovery

Transcription can consume significant battery. Foreground transcription/proofreading/summary keeps the screen awake; connect power for long tasks. iOS controls background processing. If paused or expired, return and continue from saved progress; unfinished work may repeat. Force-quitting can interrupt tasks. Cloud requests with unknown outcomes may already be charged. Preserve the app and drafts after a failure, free other space, and retry; do not uninstall to recover data.
